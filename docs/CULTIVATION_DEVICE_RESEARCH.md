BACnet, Modbus, MQTT and local vendor links are future capability slots only. No discovery, polling, scraping, subscription, equipment command, credential transport or control function is implemented for them. The only working adapter path is bounded local JSON/CSV parsing with explicit field, source channel, unit and metric mappings.

`NormalizedExportAdapter(columns=..., metric_mappings=[{source_metric,unit,source_channel,metric}], rows_key=None, max_bytes=2097152, max_rows=500).parse(content, format='json'|'csv')` returns `{readings,mapping_hints,truncated:false,read_only:true,connected:false}`. Required columns are event_id, source_device_id, source_channel, source_metric, value, unit, observed_at; quality and received_at are optional. The caller must honor a None mapping hint as unresolved, obtain a validated historical backend snapshot and call EdgeStore. No hints establish room/cycle attribution or authorize a connection.

`GrowlinkAdapter(configuration={columns,metric_mappings,format,rows_key}, fixture=<UTF-8 export text>).validate_fixture()` uses that same contract. Any destination/header/credential configuration is rejected with a fixed error. All former live entry points now raise `AdapterUnavailableError`. This security repair requires gateway integration to use the export path explicitly.

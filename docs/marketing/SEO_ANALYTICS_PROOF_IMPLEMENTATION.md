## Privacy-conscious event adapter

`frontend/src/lib/marketingAnalytics.ts` exports typed `trackMarketingEvent`, `setMarketingAnalyticsProvider`, and `setMarketingAnalyticsConsent`.

The default is no collection. Connecting an adapter alone does not enable events: explicit consent is also required. The helper honors Do Not Track and Global Privacy Control, uses no cookies/storage/identifiers/fingerprinting, queues nothing, and makes no network requests itself. Provider failures never block UI actions. Payloads contain only a predefined placement and an optional fixed content slug; do not pass user-entered values. Runtime extra fields and non-slug strings are discarded. Any future adapter must preserve these constraints and use an appropriate consent mechanism. No paid provider is required.

Supported events: homepage primary/secondary CTA, cultivation/production/retail/vertical solution selection, product tour start, integration view, FAQ expansion, beta apply, and login click. A click event must not be described as a completed application submission. No analytics provider or consent banner was introduced merely to enable this plumbing.

## Customer proof publishing gate

`CustomerProof.tsx` provides TestimonialCard, CustomerLogoRow, CaseStudyPreview, and QuantifiedResult. Evidence data and eligibility logic live in `customerProofData.ts`.

Every record must have `VERIFIED` status, explicit `approved` publication state, `publicSafe: true`, company, source, and a verification date. Pending, revoked, beta-only, planned, unverified, and incomplete records render nothing. Links and logo sources accept HTTPS or site-relative URLs. The default proof list is empty. Tests use clearly labeled fixtures that are not exported to public content.

Before adding real proof, obtain approval covering every public field and the proposed usage, retain its evidence source, and verify the result/quote against that evidence. Do not publish private evidence references automatically. Evidence owners must revoke approval when a quote, logo, or result is no longer authorized.

## Bundle boundary

The entry point lazily imports the existing application, authentication gate, beta page, and commerce portal. The same host/path checks and authentication render branches are preserved. The homepage no longer needs to fetch operator application JavaScript to render. Operator CSS is preserved to protect the shared cascade; bundle/Lighthouse measurements belong in the final browser acceptance report.

The HTML scanner bootstrap returns immediately on the public marketing hosts, loading neither QR CDN script and creating no scanner canvas. Ops/local hosts load the same two scripts sequentially with their original integrity, crossorigin, and referrer policy attributes. The unchanged decoder bootstrap completes before React mounts through a scanner-ready promise. CDN load errors still allow startup. Seven execution/source contract tests cover public exclusion, ops/local sequence, security attributes, setup before readiness, error continuation, and the mount barrier.

# Material Lineage

This module records durable seed-to-sale transformation relationships while leaving physical quantity authority in the canonical Co-Man inventory transaction ledger.

Current writers:

- Cultivation harvest output allocation
- Production Run 360 actual material consumption and finished output posting

Current federated durable source:

- Package Studio input/output relationships

Planned writers:

- Extraction source/WIP/intermediate/final transformations
- Cross-license/cross-facility legal transfer relationships
- Rework/correction paths not already represented by Package Studio

Do not calculate an independent inventory balance in this module.
